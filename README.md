# 🎨 New Bhagwati Traders — Birla Opus Paints

A modern, responsive website built for **New Bhagwati Traders**, a Birla Opus paint dealership.

The website is designed to provide customers with an easy way to explore paint products, find suitable shades, and calculate the approximate paint quantity and room requirements.

## 🚀 Features

* 🏠 Modern and responsive homepage
* 🎨 Birla Opus paint product showcase
* 🔎 Product search
* 🌈 Shade Finder
* 🧮 Paint Quantity & Cost Calculator
* 📐 Room Area Calculator
* 📱 Fully responsive design for mobile, tablet and desktop
* ⚡ Fast performance with Vite
* 🔍 SEO-friendly structure
* 📲 Progressive Web App (PWA) support

## 🛠️ Tech Stack

* **React.js** — Frontend
* **Vite** — Development & build tool
* **Tailwind CSS** — Styling
* **JavaScript** — Application logic
* **Git & GitHub** — Version control
* **Netlify** — Deployment

## 🎯 Project Goal

The goal of this project is to create a professional digital presence for a local paint dealership while also providing useful tools that help customers make better painting decisions.

Instead of being only an informational website, the project focuses on making the customer's paint-selection and quantity-estimation process easier.

## 🧰 Customer Tools

### 🎨 Shade Finder

Helps customers explore and find suitable paint shades.

### 🧮 Paint Calculator

Allows users to estimate the approximate amount of paint required for their project.

### 📐 Room Calculator

Calculates room area based on the dimensions provided by the user.

## 💻 Run Locally

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Go to the project directory:

```bash
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available on the local development server.

## 🏗️ Build for Production

```bash
npm run build
```

To preview the production build:

```bash

```
